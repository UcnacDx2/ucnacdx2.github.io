# UcnacDx2's Blog

Personal blog built with Astro, Markdown, and GitHub Pages.

## Write a post

Create a Markdown file in `src/content/blog/` with frontmatter like:

```md
---
title: "Post title"
description: "Short description"
pubDate: 2026-09-04
tags:
  - Notes
draft: false
---

Content here.
```

Push to `main` and GitHub Actions will publish the site.
