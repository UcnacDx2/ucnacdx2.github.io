这是这个博客的第一篇文章。

目前的发布方式很简单：

1. 文章写成 Markdown；
2. 保存到 `src/content/blog/`；
3. 推送到 GitHub；
4. GitHub Actions 自动构建 Astro，并发布到 GitHub Pages。

以后可以继续在这里记录技术、项目复盘和一些想法。
